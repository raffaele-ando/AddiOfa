# lib/profilo
Logica pura (senza React) del profilo: dati (nome, avatar, corso), livello attuale, badge, giorni di studio e calendario, obiettivi, simulazioni recenti.
Si prova con `cd app && npm test` (file `app/tests/unit/profilo-*.test.ts`); le definizioni (soglia del livello, condizioni dei badge) sono scritte in testa a `livello.ts` e `badge.ts`.
